# 导师汇报用 PPG 参数网页演示

本分支用于展示“PPG 信号参数输入如何影响规则判断、检索意图和报告表达”。它基于导师演示分支继续开发，不接入最新报告返修线。

## 启动方式

```bash
streamlit run streamlit_app.py --server.port 8502
```

建议使用病例：

```text
本周新增：PPG信号参数输入演示
```

这个病例不是完全失败，而是存在采集时长偏短、运动伪影中等、手指覆盖一般、接触压力偏高、环境光过亮等小问题。它适合展示系统如何把报告收敛为“先复测、不要强解释”。

## 现场展示顺序

1. 在侧边栏选择“本周新增：PPG信号参数输入演示”。
2. 打开“PPG 信号参数”标签页，看参数表、规则输出和 PPG 相关检索意图。
3. 切换到“用户报告”，展示报告如何把信号质量问题转成复测建议。
4. 切换到“证据依据”，展示检索证据仍然绑定到 PPG/无袖带局限、信号质量和家庭血压复核。
5. 如有时间，再打开“RAG 对照实验”，说明这只是演示分支，不展开最新报告优化细节。

## 建议话术

> 这版网页新增了 PPG 信号参数输入，不只是输入一个估算血压值。比如运动伪影、手指覆盖、接触压力和环境光会进入规则层，影响报告是否可以解释，以及是否优先建议重新采集。现在这部分还只是参数级展示，没有接真实波形图，也不判断这些因素会让真实血压高估还是低估；它主要用于让报告更保守、更可追溯。

## 可以主动承认的瑕疵

- 目前没有真实 PPG 波形可视化，只是结构化参数输入。
- 参数阈值还偏规则化，后续可以结合真实采集数据校准。
- 报告不会量化某个信号因素造成的血压误差方向和大小。
- 当前是导师演示分支，不是正式产品分支。
