# Module Map

- `app/api/`: report, advisor, knowledge-base, library, and admin HTTP APIs.
- `app/admin/`: RBAC, audit, jobs, configuration, integrations, metrics, and freshness.
- `app/services/`: medical-safety, retrieval, literature, full-text, and generation services.
- `admin_ui/`: Vue 3 and TypeScript administration SPA.
- `config/`: governed YAML facts and algorithm configuration.
- `knowledge_base/`: governed source metadata and derived retrieval artifacts.
- `alembic/`: administration database migrations.
- `scripts/`: ingestion, evaluation, quality, and administration entrypoints.
- `tests/`: safety, retrieval, report, library, and admin regression coverage.
