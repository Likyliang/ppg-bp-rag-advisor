# Admin V1 Productionization

Status: In Progress

This plan turns the implemented Admin V1 code into a usable single-host
internal instance and completes the remaining frontend and repository hygiene
work.

## Scope

- Remote backup and safe branch state.
- Admin database migration, first administrator, master key, API client, and integrations.
- Persistent Worker and index freshness.
- Legacy UI retirement and test/runtime filesystem hygiene.
- Productized nine-module Vue administration UI.
- Focused tests, strict quality gate, and required reviews.
